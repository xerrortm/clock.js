Now with JavaScript API.

Use HTML attributes OR control everything programmatically with Clock v2.

Create a Clock instance

Full JS control (format + timezone + type)

const clock = new Clock({
  time: "h:m:s A",
  date: "W, M D Y",
  zone: 0,
  type: 12
});

Reactive Listener System

Subscribe to real-time updates

clock.on((data) => {
  console.log(data.time);
  console.log(data.date);
});
→ Runs every second automatically → Gives formatted time + raw Date object
